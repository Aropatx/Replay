# Replay

Aplikacja Windows do nagrywania ekranu i zapisywania ostatnich chwil rozgrywki.

## Pobierz

[Pobierz Replay dla Windows — Replay-Setup.exe](https://github.com/Aropatx/Replay/releases/latest/download/Replay-Setup.exe)

Jeden stały link do najnowszej wersji. Pobierz instalator i zainstaluj Replay. Kolejne aktualizacje aplikacja pobiera automatycznie z tego samego repozytorium.

[Wszystkie wydania](https://github.com/Aropatx/Replay/releases)

## Aktualizacje

Replay sprawdza stabilne wydania po uruchomieniu i co 6 godzin, pobiera nową wersję w tle i instaluje ją po zakończeniu aplikacji. Nagrywanie nie jest przerywane. Ustawienia i zapisane klipy są zachowywane. W Ustawieniach → Aktualizacje można sprawdzić wersję, wyłączyć aktualizacje lub zainstalować gotowy pakiet od razu.

Wersja 2.0.1 wymaga jednorazowej ręcznej aktualizacji, aby otrzymać obsługę kolejnych aktualizacji. Automatyczna instalacja dotyczy wersji z instalatora.

## Wymagania i instalacja

Windows 10 1809 lub nowszy / Windows 11, 64-bit. Pobierz Replay-Setup.exe i uruchom instalator. Pakiet zawiera .NET Desktop Runtime, FFmpeg i ffprobe.

Przed ręczną aktualizacją zapisz potrzebny klip i zakończ Replay przez menu ikony w zasobniku.

## Funkcje

Bufor nagrania, zapis klipów, zrzuty ekranu, nagrywanie dźwięku systemowego i mikrofonu oraz biblioteka nagrań.

## Pierwszy klip

W ustawieniach wybierz monitor, jakość obrazu i urządzenia audio. Uruchom bufor, a po zebraniu materiału naciśnij F8, aby zapisać klip. F9 wstrzymuje lub wznawia bufor. Skróty można zmienić w ustawieniach.

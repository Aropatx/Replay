# Replay

Aplikacja Windows do nagrywania ekranu i zapisywania ostatnich chwil rozgrywki.

## Pobierz

[Pobierz instalator Replay 2.1.0 (Windows x64)](https://github.com/Aropatx/Replay/releases/download/v2.1.0/Replay-Setup-2.1.0-x64.exe)

[Wszystkie wydania](https://github.com/Aropatx/Replay/releases)

## Automatyczne aktualizacje

Od wersji 2.1.0 Replay sprawdza nowe stabilne wydania po uruchomieniu oraz co 6 godzin. Pobiera aktualizację w tle i instaluje ją po zakończeniu aplikacji, bez przerywania nagrywania. Ustawienia i zapisane klipy są zachowywane. W Ustawieniach → Aktualizacje można sprawdzić wersję, wyłączyć aktualizacje lub zainstalować gotowy pakiet od razu.

Wersję 2.0.1 trzeba jednorazowo zaktualizować ręcznie do 2.1.0, aby otrzymywać następne aktualizacje. Automatyczna instalacja dotyczy wersji z instalatora.

## Wymagania i instalacja

Windows 10 1809 lub nowszy / Windows 11, 64-bit. Pobierz plik EXE i uruchom instalator. Pakiet zawiera .NET Desktop Runtime, FFmpeg i ffprobe.

Przed aktualizacją zapisz potrzebny klip i zakończ Replay przez menu ikony w zasobniku.

## Funkcje

Bufor nagrania, zapis klipów, zrzuty ekranu, nagrywanie dźwięku systemowego i mikrofonu oraz biblioteka nagrań.

## Pierwszy klip

W ustawieniach wybierz monitor, jakość obrazu i urządzenia audio. Uruchom bufor, a po zebraniu materiału naciśnij F8, aby zapisać klip. F9 wstrzymuje lub wznawia bufor. Skróty można zmienić w ustawieniach.
